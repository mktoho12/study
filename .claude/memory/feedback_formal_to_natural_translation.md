量化子付きの命題（例：$\forall x \in \mathbb{Q}, \exists n \in \mathbb{N}, x < n$）を出すときは、機械的な読み下し（「任意の有理数 x について…」）と、それをさらに整理した自然な日本語（「任意の有理数より大きい自然数が存在する」）の両方を併記する。

**Why:** 形式を読めることと、日本語に翻訳できることは別スキル。えむけーは「形式式を見せられても、それが何を主張しているかの日本語イメージに変換できない」状態が起こる。翻訳された文を見ると当たり前に思えても、自力で翻訳するのは難しい（2026-05-05 アルキメデスの原理 §4 で気づき）。

**How to apply:** 教科書の命題を引用するとき、新しい定理を提示するとき、Socratic で形式式の理解を問うとき、必ず「形式 → 機械的な読み下し → 整理した自然語」の3段階を見せる。あるいは「翻訳してみて」と問う場合も、ヒントとして外側から読むパターン（外の量化子→内の量化子→内側の式）を示す。
