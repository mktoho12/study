LaTeX 数式（`$...$` や `$$...$$`）は Claude Code のターミナル出力では生のドル記号と TeX 記法のまま表示されてしまい、えむけーは読めない。数式を含む内容は session.md（または該当の作業ファイル）に書き出して、レンダリングできる環境（エディタのプレビュー等）で読めるようにする。

**Why:** えむけーの作業環境ではターミナル上に出した LaTeX が記号のままで判読できない。CLAUDE.md の「数式は LaTeX」は記法の指定であって、出力先までは指定していなかった。

**How to apply:**
- 短い数式（変数名や $\mathbb{R}$ 程度）はターミナルでも文脈で推測できることが多いので、文章中の最小限の挿入は許容
- ただし**論証や式変形、複数の記号が絡む説明**は session.md に書いてからターミナルでは「session.md に書きました」と案内する
- 迷ったらファイルに書く方を選ぶ
