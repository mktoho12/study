学習ノートは `~/work/study/<授業名>/<チャプター番号2桁>.<チャプター名>/<セクション番号1桁>.<セクション名>/` の3階層構造で管理する。

例：
- `~/work/study/距離空間/01.ガイダンス/3.実数/`
- `~/work/study/距離空間/03.実数/1.<セクション名>/`

**Why:** 授業・チャプター・セクションを物理的に分けることで進捗とノートを階層的に追えるようにする、というえむけーの管理方針。

**How to apply:** session.md など作業ファイルを置く場所を決めるときは、必ずセクションレベル（最深層）まで降りてから作る。チャプター直下に置かない。CLAUDE.md の「Ch03 実数：進行中」のような記述があっても、実際の作業セクションをえむけーに確認する（ガイダンス内の節か、独立したチャプターか紛らわしい場合がある）。
