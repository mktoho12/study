### 中間値の定理（IVT: Intermediate Value Theorem）

**主張**：連続関数 $f$ が $f(a) < 0$、$f(b) > 0$ を満たすとき、$a$ と $b$ の間に $f(c) = 0$ となる点 $c$ が存在する。

#### 有理数では成り立たない反例
$f(x) = x^2 - 2$ は $\mathbb{Q}$ 上の関数として、
- $f(0) = -2 < 0$
- $f(2) = 2 > 0$
- しかし $f(x) = 0$ を満たす有理数 $x$ は存在しない（$\sqrt{2} \notin \mathbb{Q}$）

→ IVT は実数の何らかの性質を本質的に使う。

#### 証明に使う道具（本講義の方針）
- 実数の連続性：**区間縮小法**を採用
- 関数の連続性：**$\varepsilon$-$\delta$ 論法**で定義

論法のスケッチ：区間をどんどん狭めていくと一点に収束し、その収束先が $f(c) = 0$ を満たす $c$ となる。

### 役割の整理（重要）

「実数の連続性」「関数の連続性」「中間値の定理」「導関数の符号と単調性」は並列ではなく、**役割が違う**：

| 項目 | 役割 |
|---|---|
| 実数の連続性 | **出発点**（公理として認める。同値条件のどれかを採用） |
| 関数の連続性（$\varepsilon$-$\delta$） | **定義**（証明するものではない） |
| 中間値の定理 | **証明する定理**（上の2つを道具にして証明） |
| 導関数が正なら関数は増加 | **証明する定理**（中間値の定理を経由して証明、応用） |

依存関係：

```
実数の連続性（公理） + 関数の連続性（定義）
         ↓ 証明
   中間値の定理
         ↓ 証明（応用）
   導関数の符号と単調性
```

→ 「公理 / 定義 / 定理」の区別は数学の作法で重要。証明対象はあくまで定理。

### 中間値の定理が必要な理由（教科書のコメント）

絵を描けば「当たり前」に見える定理だが、納得と論理的証明は別。グラフが $x$ 軸と交わっているように見えても、それが本当に $0$ を取ることを意味するかは別問題。**論理的に厳密に証明することが重要**。

### 中間値の定理の応用例
- 解析学1：「導関数が正 ⇒ 関数は増加」「微分係数 0 で極大・極小（必要条件）」
- これらは接線の傾きの直感では納得できても、厳密な証明には道具が必要
- 中間値の定理を経由することで、導関数の符号と関数の増減の関係を証明できる
- 詳細は後の講義で

### 最大値の定理（EVT: Extreme Value Theorem）

**主張**：有界**閉**区間 $[a, b]$ 上で定義された**連続**関数は、最大値および最小値を持つ。

#### 適用条件（外せない）
- 区間が**有界**かつ**閉**区間であること
- 関数が**連続**であること
- 例：開区間 $(0, 1]$ 上の $f(x) = 1/x$ は連続だが最大値なし（条件「閉」を欠くと不成立）
- 有理数の範囲でも成り立たない（最大値の対応点が有理数になる保証がない）

#### 証明に使う道具
- 実数の連続性：**ボルツァーノ・ワイエルシュトラスの定理**を採用（≒ 実数の完備性に近い性質）
- 関数の連続性

論法のスケッチ：BW定理を使って数列を構成 → 収束する部分列の存在 → 収束先が最大値を与える点。

### 中間値の定理 vs 最大値の定理 — 距離空間への一般化の観点

実数の連続性に複数の同値な述べ方がある理由：**距離空間に一般化したときに、どの性質を仮定すれば各定理が成り立つかが変わる**から。

| 定理 | 証明に使う実数の連続性 |
|---|---|
| 中間値の定理 | 区間縮小法 / 上限の存在 系 |
| 最大値の定理 | ボルツァーノ・ワイエルシュトラスの定理 系 |

距離空間においては、これらの定理が成り立つかどうかは距離空間の性質に依存する（成り立つこともあれば成り立たないこともある）。「どの性質を仮定すれば定理が成り立つか」を見極めるために、各定理の証明に何を使ったかを把握することが重要。

→ **後の講義で距離空間の一般論をやる際に、最大値の定理に再び戻ってくる**。

### 最大値の定理の応用
- 平均値の定理の証明
- 連続関数の積分可能性の証明（**一様連続性**を経由）
- 解析学1では具体的な関数で積分したので一般論は意識されなかったが、この一般論が「連続関数は積分可能」「$C^1$ 級なら平均値の定理」などをきちんと正当化する

### まとめ

**教科書のまとめ**

解析学の基礎的な定理として、この距離空間の講義の中で扱う主な内容を紹介した。中間値の定理は区間縮小法と $\varepsilon$-$\delta$ 論法に基づく関数の連続性を用いて証明され、導関数の符号と関数の増減の関係など、微積分の基本的な結果の証明に応用される。最大値の定理はボルツァーノ・ワイエルシュトラスの定理を用いて証明され、平均値の定理の証明や連続関数の積分可能性の証明に応用される。さらに、各定理の証明に使われる実数の性質を把握することが、距離空間における定理の成立条件を見極める鍵となる。
