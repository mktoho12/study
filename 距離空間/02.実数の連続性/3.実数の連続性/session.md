# Ch02 §3 実数の連続性

Ch02 の本題回。$\mathbb{R}$ と $\mathbb{Q}$ を決定的に区別する性質「実数の連続性」を **公理として認め**、そこから諸定理を導く立場（公理的アプローチ）を採用する。

開始: 2026-05-05

---

## このセクションで学ぶこと

- 実数の連続性は、実数全体の集合が持つ最も重要な性質の一つ
- 数直線上で「連続的に」並んでいることを数学的に表現したもの
- 有理数と実数を区別する決定的な特徴
- 前セクションの上限の概念を用いて、この性質を述べる
- このセクションでは**背理法**による証明技法を用いる

アプローチ：実数そのものを定義するのではなく、実数全体の集合がどのような性質を満たすかを明確にして、そこから導かれる性質を調べる。線形代数で「ベクトルそのもの」ではなく「ベクトル空間の性質」を定義するのと似ている。

---

## $\mathbb{R}$ の基本的性質（$\mathbb{Q}$ と共通）

1. **四則演算**：加法・減法・乗法・除法（ゼロ除算除く）が定義され、交換法則・結合法則・分配法則・逆元の存在
2. **順序構造**：大小関係が定義され、推移律（$a < b \land b < c \Rightarrow a < c$）、演算との整合性（$a < b \Rightarrow a + c < b + c$、$c > 0 \Rightarrow ac < bc$）

→ これらは $\mathbb{Q}$ でも成り立つ。$\mathbb{R}$ と $\mathbb{Q}$ を区別するには「さらなる性質」が必要 = **実数の連続性**。

---

## 実数の連続性（公理）★

**定義：**

$$A \subseteq \mathbb{R},\ A \neq \emptyset,\ A \text{ が上に有界} \implies \sup A \text{ が存在する}$$

直感的に言えば：「$\mathbb{R}$ の空でない部分集合 $A$ が上界を持つならば、$A$ は上限を持つ」。

これが今回の章のタイトルにもなっている性質。$\mathbb{R}$ と $\mathbb{Q}$ を**決定的に**区別する。

---

## 確認テスト（2026-05-05）

5問満点。

- Q1（公理の3要素）：「空でない」「上に有界」 ⟹「上限を持つ」
- Q2（公理の適用判定）：適用可は「空でない & 上に有界」を両方満たす集合のみ。$\mathbb{R}$ や $\mathbb{N}$ は上に有界でないので不可、$\emptyset$ は空集合なので不可
- Q3（sup の計算）：$\{1-1/n\} \to 1$、$(0,1] \to 1$、$\{(-1)^n n\} \to$ なし
- Q4（$\mathbb{Q}$ で公理が破れる典型例）：$\{x \in \mathbb{Q} \mid x^2 < 2\}$。空でない・上に有界（例：2）なのに $\mathbb{Q}$ の中に sup が存在しない
- Q5（max と sup の違い）：$\max A$ は $A$ に属する必要がある、$\sup A$ は属さなくてよい

**保留 / 次回リベンジ**：Q4 の「$\mathbb{Q}$ で sup が存在しない」の厳密な証明は、3つのケース分け（$(\sup A)^2 < 2$ / $> 2$ / $= 2$）で各々矛盾を導く形。証明力をつけてから戻る。
