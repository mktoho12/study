# Ch02 §4 アルキメデスの原理

開始: 2026-05-05

---

## アルキメデスの原理

**形式：** $\forall a > 0,\ \forall b > 0,\ \exists n \in \mathbb{N},\ na > b$

**日本語：** 任意の正の数 $a, b$ に対し、$a$ を $n$ 回足せば $b$ を超える自然数 $n$ が存在する

**意味の核：** $\mathbb{N}$ は $\mathbb{R}$ の中で上に有界でない（同値）

**証明：** 背理法 + 実数の連続性公理（sup の存在を使う）

**運用パターン：** 示したい不等式を $n \times \text{何か} > \text{何か}$ の形に変形して $a, b$ を読み取る
- $1/n < \varepsilon$ → $a = \varepsilon, b = 1$
- $r < n$ → $a = 1, b = r$

---

## 重要な注意：$\mathbb{Q}$ でもアルキメデスは成立する

| 性質 | $\mathbb{R}$ | $\mathbb{Q}$ |
|---|---|---|
| 連続性公理（sup の存在） | ◯ | ✗ |
| アルキメデスの原理 | ◯ | ◯ |

連続性 ⟹ アルキメデス（一方向）。逆は成り立たない（$\mathbb{Q}$ が反例）。連続性公理が壊すのは「sup の存在」のような完備性に関わる性質だけ。

## 確認テスト（2026-05-05）

5問満点。

- Q1（穴埋め）：$\forall a > 0, \forall b > 0, \exists n \in \mathbb{N}, na > b$
- Q2（同値命題）：$\mathbb{N}$ は $\mathbb{R}$ で上に有界でない
- Q3（計算）：$a = 0.001, b = 5 \to n = 5001$
- Q4（応用）：$1/n < \varepsilon$ → $a = \varepsilon, b = 1$
- Q5（応用）：$r < n$ → $a = 1, b = r$
