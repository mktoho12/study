# Ch02 §6 デデキントの切断

開始: 2026-05-05

---

## 動機

§3〜§5 では「実数の連続性」を**公理として認める**立場で議論してきた。本セクションでは、そもそも連続性を満たす集合が**存在するか**を問い、$\mathbb{Q}$ から実数を**構成**する方法（デデキント切断）を与える。

---

## 切断の定義

$\mathbb{Q}$ の切断 $(A, B)$ とは、次の4条件を満たす $\mathbb{Q}$ の部分集合の組：

1. $A \neq \emptyset$、$B \neq \emptyset$
2. $A \cup B = \mathbb{Q}$ かつ $A \cap B = \emptyset$
3. $\forall a \in A, \forall b \in B,\ a < b$
4. $A$ は最大元を持たない

**直感（ナイフの比喩）：** $\mathbb{Q}$ の数直線をナイフで切る。$A$ が左の塊、$B$ が右の塊。「$A$ に最大元なし」の規約により、境目に対して切断が一意に対応する。

---

## 2つのパターン

| ナイフが… | 境目 | $A$ の最大元 | $B$ の最小元 | 例 |
|---|---|---|---|---|
| 有理数 $r$ に当たる | 有理数 | なし | あり（$r$）| $r = 1$ など |
| 空を切る（有理数の隙間） | **無理数** | なし | なし | $\sqrt{2}, \sqrt{3}, \ldots$ |

**核心の発想**：「ナイフが空を切ったその切断面に、無理数が住んでいる」（えむけーの表現）

$\sqrt{2}$ の切断：$A = \{q \in \mathbb{Q} \mid q < 0 \lor q^2 < 2\}$、$B = \{q \in \mathbb{Q} \mid q > 0 \land q^2 > 2\}$

$\sqrt{2}$ という名前は出てこない（まだ存在しない）。**有理数の四則と順序だけ**で書けてる。そしてこの切断 $(A, B)$ そのものが「新しい数 $\sqrt{2}$」として誕生する。

---

## 構成の仕組み

**切断全体の集合：**
$$\mathbb{R}' = \{(A, B) : (A, B) \text{ は } \mathbb{Q} \text{ の切断}\}$$

集合論の公理（冪集合・直積）により、$\mathbb{R}'$ は $\mathcal{P}(\mathbb{Q}) \times \mathcal{P}(\mathbb{Q})$ の部分集合として存在する。

**順序関係：**
$$(A, B) \leq (A', B') \stackrel{\text{def}}{\iff} A \subseteq A'$$

$A$ が広いほど境目が右にあるので、これが自然な大小関係になる。集合の包含関係だけで定義しているのが工夫。

---

## クライマックス：連続性公理が成立

「$\mathbb{R}'$ の上に有界な部分集合 $X$ には上限が存在する」ことが**証明**される。証明の要旨：
- $A^* = \bigcup_{(A,B) \in X} A$ と置く
- $(A^*, \mathbb{Q} \setminus A^*)$ が切断であることを4条件で確認
- これが $X$ の上限であることを示す

これにより**§3 の「公理」が、$\mathbb{R}'$ では「定理」として成立**する。

---

## メタな含意

§3 で公理として仮定した連続性が、§6 で構成した $\mathbb{R}'$ で**実際に成り立つ**ことが示せた。これは「公理を証明した」のではなく「**公理を満たす具体物が存在する**ことを示した」という意味。

プログラミングで言えば：
- 公理 = `interface Real { hasContinuity: true }`（仕様の宣言）
- 構成 = `class DedekindCut implements Real { ... }`（具体実装）

「実装可能な仕様＝意味のある仕様」が示せたことで、§3 の公理は空約束ではなかった。これが論理学で言う「**モデル構成による無矛盾性の証明**」。
