# §2 収束の定義　練習問題

## 問1（極限を答えよ）

次の数列の極限は？（証明不要）

$$a_n = 4 - \frac{1}{n^2}$$

## 問2（収束 / 発散の判定）

次の数列は収束するか？ 収束するなら極限を、しないなら一言その理由を。

$$a_n = (-1)^n + 1$$

## 問3（定義の論理式）

「数列 $(a_n)$ が実数 $\alpha$ に収束する」をε-N の論理式で書け。

## 問4（否定の論理式）

「数列 $(a_n)$ が実数 $\alpha$ に**収束しない**」を論理式で書け。

（量化子の否定：$\neg \forall \to \exists$、$\neg \exists \to \forall$、不等式の反転 を使う）

## 問5（量化子の順序の意味）

ε-N 定義の量化子の順序を入れ替えて、次の条件を考える：

$$\exists N \in \mathbb{N}, \forall \varepsilon > 0, \forall n > N, |a_n - \alpha| < \varepsilon$$

（元は $\forall \varepsilon, \exists N$ の順番だったところを、$\exists N, \forall \varepsilon$ に入れ替えた）

この条件は何を意味する？ 元の収束より **強い・弱い・同じ・無関係** のどれ？

ヒント：「$\forall \varepsilon > 0, |x| < \varepsilon$」を満たす $x$ は何か？ から考えると見えてくる。
